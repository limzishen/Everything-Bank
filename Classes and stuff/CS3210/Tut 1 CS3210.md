# Overview 
- `generateLargeArray`: fills a `vector<int>` of length `size` with `rand() % max_value`, so each element is in `[0, max_value)`.
- `my_sort`: **bubble sort**. The inner loop compares adjacent pairs and swaps if out of order; the bound `n - i - 1` shrinks each pass because after pass `i`, the `i` largest elements have "bubbled" to their final positions at the tail. Ascending order.
- `main`: generates a 10,000-element array, sorts it, prints the last 5 (i.e. the 5 largest).
