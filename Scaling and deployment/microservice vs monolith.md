# Microservice
Multiple smaller services communicating and working together

## Pros: 
1. each services can be deployed and worked on independently 
2. Easier to scale horizontally
3. individual service can fail without crashing the whole system 
4. more flexibility 
5. freedom to choose the best technology for each service 
## Cons: 
1. Greater complexity 
2. Harder to trace bugs if it arises 
3. Slower communication due to network delay 


# Monolith 
One application that handles everything 

## Pros: 
1. easier to trace bugs
2. Simple development 
3. faster communication 

## Cons: 
1. Harder to scale horizontally 
2. Limited tech choices 
3. Entire thing can fail if a part of it fails
