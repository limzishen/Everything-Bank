# Domain 
dom(A) - set of all possible value in A 

# Relation 
R(A, B, C, D ...) - relation schema with name R and n attributes 

# Relational database schema 
A set of relation schemas + data constraints 

# Relational database 
Collection of tables 

# Key constraints 
## Super key 
A subset of attributes that uniquely identifies a tuple in a relation 

## Key 
A superkey thats minimal ie. you cant take a subset of the superkey and form another superkey 

## Candidate key 
The set of all keys 

## Primary key 
The Key you choose 
never NULL 

## Surrogate key 
You can form any key from the given relation, make your own 


# Foreign key 
A subset of attributes of relation A if it refers to a primary key in B
