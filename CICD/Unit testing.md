# Unit testing goals 
- Early error detection 
- Simplify debugging 
- Faster developmental cycle
- Documentation of what the code is supposed to do 


# Code coverage 
The percentage of code coverage is how many lines of code is ran in the test case as compared to the lines written. Aim for like 80% 

# FIRST Principles 
1. Fast 
2. isolated 
3. Repeatable 
4. Self Validating 
5. thorough 


# AAA Testing 
Arrange - setup up any classes 
Act - run it 
Assert - check if output should be accepted
